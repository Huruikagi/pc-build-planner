# サイト固有抽出を作成する

この Skill は開発用であり、利用者の Capture 操作、実サイトへのアクセス、ページ資料の取得を開始しない。対象は開発者が指定した一つのページだけである。

## 最初に確認する入力

次の入力を、順序を変えずに一つずつ確認する。各入力が明示され、有効だと確認できるまで、次の入力やページ資料の内容を扱わない。

1. 対象ページ URL
2. 製品カテゴリ
3. 取得したい項目
4. 保存済みページ資料のローカルパス
5. 判断記録のローカル出力先

判断記録の出力先は、開発者が明示したリポジトリ外のローカルパスだけを受け入れる。リポジトリ内のパス、未指定の既定パス、リポジトリ外か確認できないパスは受け入れない。ページ本文、HTML、画像、商品値、認証情報をリポジトリ、判断記録、Skill の出力へ書き込まない。判断記録には、それらの内容の代わりに資料のローカル識別子だけを記す。

いずれかの入力が欠ける、空である、またはこの制約を満たさない場合は、そこで停止する。登録可能な抽出候補、コード変更、検証、登録を出してはならない。

## 停止結果の形式

停止時は、次の四項目だけをこの順で示す。候補、selector、ページ資料の内容、商品値、認証情報を含めない。

1. 対象
2. 停止段階
3. 理由
4. 次に必要なもの

停止結果は次の条件で返す。

| 停止段階 | 対象 | 理由 | 次に必要なもの |
| --- | --- | --- | --- |
| 入力確認 | 欠けた、空の、または制約に合わない入力 | 固定順の必須入力を確認できない | 該当する入力。判断記録の出力先なら、リポジトリ外であることを確認できる開発者指定のローカルパス |
| 保存資料の読取 | 指定された保存済みページ資料のローカルパス | ファイルを読めない、またはページ資料として扱えない | 読み取れる保存済みページ資料のローカルパス |
| ページ識別 | 対象ページ URL と保存済みページ資料 | 資料から対象ページを一意に識別できない | 対象ページを識別できる URL と対応する保存済みページ資料 |
| 要求項目の確認 | 取得したい項目 | 資料に指定項目が明記されず、検出できない | 当該項目が明記された保存済みページ資料、または取得したい項目の見直し |

保存資料の読取、ページ識別、要求項目の確認は、利用条件の判定が許可となった後だけに行う。利用条件が禁止または判断不能のときの停止と判断記録は、この Skill の後続の規約判断手順に従う。ここで保存資料を読んだり、候補を作ったりしてはならない。

## この段階の境界

この入力確認を通っても、登録可能な抽出候補はまだ出さない。利用条件の判定、保存資料からの候補生成、検証、`page-capture` への登録または更新、再生成時の既存登録の扱いは、それぞれ後続の手順でのみ行う。

## 利用条件を判定する

入力確認を通過した後、保存済みページ資料を読んだり、ファイルの内容を確認したりする前に、対象サイトの利用条件を判定する。この Skill は実サイトへアクセスしないため、開発者が示した利用条件の根拠 URL と確認日だけを判定根拠として扱う。根拠が抽出作成を許可することを明示できるときは `許可`、禁止するときは `禁止`、どちらとも確認できないときは `判断不能` とする。推測で `許可` にしてはならない。

判断ごとに、開発者が指定した判断記録の出力先へ、対象ページ URL、製品カテゴリ、取得したい項目、保存済みページ資料のローカル識別子、判断（`許可`、`禁止`、または `判断不能`）、根拠 URL、確認日を記録する。判断記録にはページ本文、HTML、画像、商品値、認証情報を書かない。

### 禁止または判断不能

判断が `禁止` または `判断不能` なら、同じ判断記録に停止理由と次に必要な確認を記録して、直ちに停止する。保存済みページ資料の読取、候補生成、検証、登録、既存登録の更新を開始してはならない。停止結果は次の四項目だけをこの順で返す。

1. 対象: 対象サイトの利用条件
2. 停止段階: 利用条件の判定
3. 理由: `禁止` なら抽出作成を許可しない根拠、`判断不能` なら許可または禁止を確認できない根拠
4. 次に必要なもの: `禁止` なら抽出作成を許可する明示的な根拠、`判断不能` なら利用条件の結論を確認できる根拠 URL と確認日

この停止結果には、候補、selector、保存済みページ資料の内容、商品値、認証情報を含めない。

### 許可

判断が `許可` のときだけ、判断記録を残した後に、後続の保存済みページ資料の読取、候補生成、検証の手順へ進める。ここで登録を行ったり、登録可能な候補を出したりしてはならない。後続の手順がまだ満たされない限り、`page-capture` への登録または既存登録の更新は行わない。
