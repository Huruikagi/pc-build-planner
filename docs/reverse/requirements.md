# 要求仕様（v0.4.0 からのリバース）

本書は、稼働する v0.4.0 の実挙動から逆算した**プロダクトとしての要求**である。
実装構造には一切言及しない。「何のために誰が何をするか」だけを記述する。

- 出典: タグ `v0.4.0`（`395189a`）を実ビルドし、Chrome 上で全画面を操作して確認した挙動
- v0.5.0 以降の移行途中の内部構造は本書の対象外

---

## 1. プロダクトの目的

Web 上で見つけた PC パーツを、閲覧の流れを止めずに手元へ溜め、
プロジェクト単位で構成を検討し、基本的な規格の整合性を確認する。

中心にある体験は「パーツを登録して終わる」ではなく、
**検討中の候補を溜めて、何度でも戻って比較・補正し続ける**ことにある。
その性質から Chrome 拡張という形態を選んでいる。

## 2. 対象利用者

自作 PC の経験があり、複数の EC サイト・メーカーサイトを行き来しながら
新規構成やアップグレードを検討する個人。初心者向けの組立手順は対象としない。

## 3. 解決する課題

| # | 課題 | 対応する要求 |
|---|---|---|
| R1 | 候補情報がサイトごとに散らばり、スプレッドシートへの手作業転記が発生する | 閲覧中のページから明示操作で取り込める |
| R2 | 情報が揃わない商品は記録の対象から漏れる | 欠損・未分類のまま保存でき、後から補正できる |
| R3 | 検討対象が増えると組み合わせの整合性を追えなくなる | 確認済みの値だけから基本規格の整合性を判定する |
| R4 | 同じ商品を複数ページで見ており、比較の軸が定まらない | 一つのパーツに複数の取得元を束ねられる |
| R5 | アカウント作成や外部サービス依存を避けたい | ローカル完結で動作する |

## 4. 中核となる要求

### R-1 取り込み（Capture）
利用者の明示操作を起点に、閲覧中のページから取得可能な商品情報を抽出する。
サイト固有のスクレイピングロジックは持たず、構造化メタデータ（JSON-LD / OpenGraph）
と汎用的な DOM 手掛かりだけに依存する。結果として国・言語に依存しない。

抽出の完全性は前提にしない。取得できた項目・できなかった項目・その根拠を提示し、
利用者が確認して確定させる。

### R-2 候補の蓄積（Candidate）
取り込んだ商品を、プロジェクトに属するパーツ候補として保存する。
URL しか分からない状態でも保存でき、カテゴリ未分類も正常な状態として扱う。

一つのパーツは複数の取得元（販売ページ／メーカー商品紹介ページ）を持つ。
うち一つがプライマリとなり、価格の基準になる。取得元からは元ページへ戻れる。

### R-3 構成の管理（Current Build）
プロジェクト内の候補から、いま採用するパーツと数量を選び、
一つの「現在構成」として保持する。カテゴリごとに何を採用しているかが一望できる。

### R-4 互換性の確認（Compatibility）
現在構成に対して、利用者が確認した正規化済み属性だけから
基本規格の整合性を評価する。判定は「一致／不一致／情報不足」の 3 値で、
必ず根拠を添える。**情報不足を不整合と誤認しない**ことを絶対条件とする。

### R-5 表示言語（i18n）
UI 文言は日本語・英語を持つ。表示言語は**ブラウザの UI 言語に従う**。
アプリ内に言語切り替えは持たない。言語によって挙動は変わらない。
ロケール別の日付・数値・通貨フォーマットは対象外。

## 5. 通貨・国への非依存

通貨は商品ページから取得した値をそのまま尊重し、取得できなかった場合に
特定通貨を推測しない。未確定は「不明」として保持する。
為替換算・レート取得は対象外。

## 6. 非機能要求

| 項目 | 要求 |
|---|---|
| 動作環境 | Chrome 116 以降 / Manifest V3 |
| データ所在 | 完全ローカル。サーバー・アカウント・同期を持たない |
| ネットワーク | 利用者が明示操作したページの取得以外に外部通信しない |
| 権限 | ページ読み取りは利用者操作の都度に限る |
| データ保全 | 保存は原子的に行い、中断でデータを壊さない |
| データ喪失 | 拡張の削除・データ破損による喪失は許容する。退避機能は持たない |

## 7. 対象外（v0.4.0 時点で意図的に持たない）

Web アプリ / バックエンド / アカウント / 同期 / 他ブラウザ対応 /
Chrome Web Store 公開 / AI による抽出 / サーバー側スクレイピング /
価格・在庫の自動監視 / 網羅的な商品マスター / 高度な互換性判定
（電力計算、物理干渉、ケースクリアランス等）/
**バックアップ・復元（データのエクスポート・インポート）** /
**アプリ内の表示言語切り替え**
